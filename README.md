# Vite + TypeScript Web App

This project is set up with Vite, TypeScript, Tailwind CSS, and Firebase SDK configured for Netlify deployment.

## Deployment
To deploy to Netlify:
1. Authenticate to Netlify.
2. Link the repository.
3. Set the required environment variables:
   - `VITE_FIREBASE_API_KEY`
   - `VITE_FIREBASE_AUTH_DOMAIN`
   - `VITE_FIREBASE_PROJECT_ID`
   - `VITE_FIREBASE_STORAGE_BUCKET`
   - `VITE_FIREBASE_MESSAGING_SENDER_ID`
   - `VITE_FIREBASE_APP_ID`

## Environment Variables
Ensure to set the following environment variables in Netlify:
- VITE_FIREBASE_API_KEY
- VITE_FIREBASE_AUTH_DOMAIN
- VITE_FIREBASE_PROJECT_ID
- VITE_FIREBASE_STORAGE_BUCKET
- VITE_FIREBASE_MESSAGING_SENDER_ID
- VITE_FIREBASE_APP_ID
